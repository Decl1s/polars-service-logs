# Концепция

Проект ежедневной серии от 15 октября 2026 года для начинающего дата-инженера.
Полностью синтетические журналы трёх сервисов, обработка на Polars, выгрузка Parquet
по дате UTC и почасовая витрина. Запуск локальный, без облака и сервера базы.

Новые навыки: выражения LazyFrame, строгая типизация JSON, группировка по часу,
линейный p95, файловые разделы и полная пересборка снимка.
Одна новая основная технология вместо добавления множества инфраструктурных сервисов.

Пользователь делегировал выбор ежедневных мини-проектов. Приняты допущения:
Python 3.11–3.12, Linux и Windows, русский интерфейс, синтетический вход,
фиксированный набор сервисов, полная замена результата, запрет конфликтующих событий.

Готовность: демо даёт ожидаемые количества, повтор не удваивает запросы,
p95 и доли ошибок проверены на ручном примере, плохие строки изолируются,
конфликт или сбой не уничтожает прежний результат. Есть инструкция и подробный конспект.

Публичная публикация допустима только для проверенных исходников по явному списку,
без личных данных в содержимом файлов. Метаданные авторства публичной истории Git
доступны посетителям репозитория. Внешний доступ и публикация не считаются
успешными по одному факту локальной готовности.

Следующие возможности: несколько выходных файлов в большом разделе,
инкрементальная загрузка с явным контрактом источника, сравнение движков выполнения,
проверки распределения задержек и мониторинг свежести поставки.
